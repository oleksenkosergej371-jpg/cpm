# Noir Wolf Cut — Customizable Player Models

Minecraft character **Noir** with a three-dimensional Wolf Cut hairstyle for the Customizable Player Models (CPM) mod.

## Project
The editable CPM source is `Noir_WolfCut.cpmproject` (to be uploaded). The model has not yet been confirmed working inside Minecraft 1.21.1 with CPM.

## Installing and using
1. Open the CPM editor in Minecraft.
2. Use **File → Load Project** to load the `.cpmproject`.
3. Inspect head, hair, texture and animations before exporting.
4. Export through CPM. A public GitHub URL to the editable project alone does **not** load the 3D model on multiplayer servers.
5. Depending on the server's CPM support, export to the appropriate `.cpmmodel` or compatible skin/model data as offered by CPM.

The original Blockbench source and exported model data may be added later.
